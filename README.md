# WinAPI 커비 모작 프로젝트

![커비 이미지](./title.png)

## 프로젝트 개요
- **프로젝트명**: WinAPI 커비 모작 프로젝트  
- **개발 기간**: 2025년 7월 ~ 8월 (약 6주)  
- **개발 환경**: C++ / Visual Studio / WinAPI  
- **목적**:  
  - 운영체제와 프로그램의 상호작용 이해
  - 객체지향 개념(C++ 심화) 실전 적용  
  - 게임 엔진 내부 구조(루프, 씬, 오브젝트, 생명주기) 이해  
  - 저수준 그래픽 처리 경험 

---

## 주요 구현 기능

### 1. 캐릭터 & 전투 시스템
- 이동, 점프, 공격, 빨아들이기 → 삼키기 → **카피 능력 획득**
- 충돌 처리 및 능력별 전투 로직 구현
- **애니메이터 시스템 구현**: 상태 전환 테이블 기반 FSM(Finite State Machine)으로 애니메이션/상태 제어
- 예: `IDLE → JUMP → FALL → BOUNCE` 등 명확한 상태 전환 구조

### 2. 물리 & 충돌 시스템
- **리지드바디(Rigid Body)**: 객체의 위치·속도·중력 등을 관리  
- **콜라이더(Collider)**: 충돌 영역을 정의, 객체 간 상호작용 처리  
- 충돌 시 이벤트 트리거 → 공격 판정, 아이템 습득, 몬스터 피격 등 동작 구현

### 3. 몬스터
- **웨이들 디, 브론토버트, 웨이들 두, 핫 헤드, 스파키, 위스피 우드(보스)** 구현
- 일부 몬스터는 **카피 능력 보유** → 삼킨 후 커비가 해당 능력 사용 가능
- **상속 기반 구조**로 설계, **컴포넌트 방식의 확장성** 필요성 학습

### 4. 보스 페이즈 전환
- **트리거 박스(Trigger Box)** 활용 → 특정 구역 진입 시 보스 전투 시작  
- 이벤트 드리븐 방식으로 보스의 상태 변화 구현

### 5. 스테이지 에디터
- 몬스터와 타일을 자유롭게 배치  
- 배치 내용 → 파일로 저장  
- 스테이지 씬에서 불러오기

### 6. 매니저 클래스 (싱글톤 기반)
- 오디오 매니저, 입력 매니저, 리소스 매니저 등  
- 프로젝트 전반에서 **재사용 가능한 관리 구조** 구현

### 7. 월드 & 카메라 시스템
- **월드 좌표와 뷰 좌표의 차이**를 이해하고, 이를 기반으로 카메라 이동 처리  
- 플레이어를 중심으로 월드가 스크롤되는 구조 구현  
- 카메라가 플레이어 이동을 따라가되, 스테이지 경계를 벗어나지 않도록 제어
- 카메라 흔들림 효과 연출
